# Documentation

## 中文

- [revm run](./run.md): 启动 Linux rootfs session 并执行命令。
- [revm dockerd](./dockerd.md): 启动内置容器运行环境，并通过 Docker CLI 或 Podman CLI 使用。
- [revm attach](./attach.md): 连接已有 session，打开交互 shell 或执行命令。
- [revm ctl](./ctl.md): 控制已有 session 的控制面，包括展示端口映射、端口暴露和端口取消暴露。

## English

- [revm run](./run.en.md): boot a Linux rootfs session and execute commands.
- [revm dockerd](./dockerd.en.md): start the built-in container runtime and use it through Docker CLI or Podman CLI.
- [revm attach](./attach.en.md): connect to an existing session, open an interactive shell, or execute a command.
- [revm ctl](./ctl.en.md): control an existing session's control plane, including port listing, port export, and port unexport.
